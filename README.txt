MIS CUENTAS - VERSION GRATIS PARA CELULAR

Esta versión NO usa servidor ni base de datos.
Los datos se guardan en localStorage del navegador de cada dispositivo.

Para probar:
1. Abre index.html en el navegador.
2. Agrega personas y abonos.
3. Usa Guardar respaldo para descargar una copia JSON.

Para publicarlo gratis:
- Puedes usar GitHub Pages.
- Solo necesitas publicar index.html.

IMPORTANTE:
Cada celular guarda datos independientes. No hay sincronización entre celulares.
